# v2.2.1 — Copy Discord Report

This version removes the Discord webhook approach and adds a manual **Copy Discord Report** button to the website.

The copied report always uses:
- 15-mile radius from Clearwater
- active stores only (0-event stores excluded)
- title: Pinellas Lorcana Store Activity Report
- current-tier denominators for Standard and Legendary stores
- remaining events / unique players / tickets needed to advance
- full tracker URL and unofficial-tool disclaimer

## Update these files
- public/app.js
- public/index.html
- public/styles.css

## Only if you already applied the webhook v2.2 files
Also restore:
- package.json
- .github/workflows/deploy-pages.yml

And delete:
- src/discord-report.js

If you never applied v2.2, you do not need to touch package.json, the workflow, or src.
