# v2.2 Discord Weekly Report Patch

This patch adds an automatic weekly Discord summary after the Monday Play Hub update.

## Files to update

- `package.json`
- `src/discord-report.js` (new)
- `.github/workflows/deploy-pages.yml`

## Behavior

- Website sync still collects up to 40 miles.
- Discord report always uses the website defaults:
  - 15 miles from Clearwater
  - stores with 0 events excluded
- Scheduled Monday runs automatically post to Discord.
- Normal commits/pushes do NOT post to Discord.
- Manual workflow runs have an optional `post_to_discord` checkbox for testing.
- If `DISCORD_WEBHOOK_URL` is not configured, the Discord step safely skips rather than breaking the website deployment.

## Required GitHub secret

Create a repository Actions secret named exactly:

`DISCORD_WEBHOOK_URL`

Paste the Discord channel webhook URL as its value. Never commit the webhook URL into the repository.
